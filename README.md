# Aditya Rahman - Portfolio

Website portofolio pribadi: Web Development & Cybersecurity.

## Tech Stack

- **Framework**: Next.js (App Router) + TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Audio Experience**: Web Audio API
- **Internationalization**: Multi-language (`/id`, `/en`)

## Menjalankan Proyek

```bash
# Install dependencies
bun install

# Jalankan development server
bun dev
```

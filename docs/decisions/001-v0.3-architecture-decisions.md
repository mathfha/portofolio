# ADR 001: Keputusan Arsitektur & Lingkup v0.3

Tanggal: 2026-10-24  
Status: Accepted

## Konteks

Pengembangan portofolio personal "Workspace" Aditya Rahman memasuki tahap penentuan arsitektur teknis dan eliminasi kompleksitas yang tidak esensial.

## Keputusan

1. **Routing Dwibahasa Berprefix**:
   - Semua halaman konten berada di bawah prefix `/id` atau `/en`.
   - Rute root `/` hanya melakukan redirect sementara (status 307) berdasarkan header browser `Accept-Language`.
2. **Top Bar & Modul Jam**:
   - Jam utama di tengah menampilkan Waktu Indonesia Barat (WIB) secara live.
   - Jam lokal pengunjung ditampilkan sebagai tooltip/popover pada modul jam tersebut untuk menyederhanakan ruang status bar.
3. **Penyederhanaan Dokumentasi Template**:
   - `API_CONTRACTS.md` dan `SECURITY.md` dari template dasar dieliminasi karena proyek merupakan situs statis tanpa backend. Aspek keamanan (obfuscation email & CSP) digabungkan ke dalam [docs/ARCHITECTURE.md](../ARCHITECTURE.md).
4. **Distribusi File CV**:
   - Disediakan 2 file PDF terpisah (`cv-id.pdf` dan `cv-en.pdf`). Tombol download secara dinamis mengunduh file yang sesuai dengan bahasa aktif.
5. **Penanganan Workspace Kosong (八〜十)**:
   - Tidak dibuatkan halaman atau rute statis agar tidak menjadi *thin content* di mata mesin pencari.
   - Menggunakan interaksi client-side (toast notification) yang mengarahkan pengunjung kembali ke workspace `一`.
